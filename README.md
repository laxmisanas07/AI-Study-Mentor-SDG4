# 🎓 AI Study Mentor – SDG 4: Quality Education

> An AI-powered educational chatbot built with **Botpress** to support **United Nations Sustainable Development Goal (SDG) 4: Quality Education** by providing students with instant, beginner-friendly learning assistance.

## 📖 Project Overview

**AI Study Mentor** is an educational chatbot designed and developed by **Ms. Laxmi Ananda Sanas** using **Botpress**. The chatbot helps students learn Artificial Intelligence, Python, Machine Learning, Deep Learning, and Natural Language Processing (NLP) through simple, easy-to-understand conversations.

The project aligns with **United Nations Sustainable Development Goal (SDG) 4: Quality Education**, aiming to make quality educational support accessible anytime and anywhere.

---

## 🌍 SDG Alignment

### 🎯 SDG 4 – Quality Education

This project contributes to **SDG 4** by:

- 📚 Providing free and accessible educational guidance
- 🤖 Offering AI-powered learning assistance 24/7
- 💡 Encouraging self-paced learning
- 🎓 Simplifying complex technical concepts
- 🌐 Making educational support available beyond classroom hours

---

## ❓ Problem Statement

Many students struggle to find immediate academic support outside classroom hours. Limited access to tutors and educational resources can reduce learning efficiency and confidence.

AI Study Mentor addresses this challenge by providing an intelligent educational assistant that is always available to answer questions and guide students.

---

## 🎯 Project Objectives

The chatbot aims to:

- Provide instant answers to educational questions
- Explain AI and programming concepts in simple language
- Help students learn Python programming
- Support Machine Learning and Deep Learning education
- Explain Natural Language Processing concepts
- Offer study tips and learning strategies
- Promote independent and self-paced learning
